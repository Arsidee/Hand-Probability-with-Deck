# YGO Hand Probability — with Deck

Builds on the [Hand Probability Simulator](https://arsidee.github.io/Hand-Probability/) by adding a one-click Premade Deck loader.

**[Live Demo](https://arsidee.github.io/Hand-Probability-with-Deck/)**

## Features

- All features from the base project (deck builder, Deal Hand, Going 1st/2nd toggle)
- **Premade Deck button** — loads a full 41-card personal deck instantly
- Deck validation (40–60 cards) with toast messages
